# 组件规范 · 校友活动与捐赠项目管理系统

所有尺寸、色值均取自 `design-system.md`，实现阶段 1:1 复刻，不得另行发挥。

## 1. 按钮 Button

| 类型 | 背景 | 描边 | 文字 | 高度 | 内边距 | 场景 |
|---|---|---|---|---|---|---|
| 主按钮 | `#5B2533` | 无 | `#fff` | 34px | 0 16px | 提交、保存、确认核对 |
| 次按钮 | `#fff` | `1px #E7DFDC` | `#2B2321` | 34px | 0 16px | 取消、重置、导出 |
| 文字按钮 | 透明 | 无 | `#7A3947` | 30px | 0 6px | 表格行内「查看/编辑」 |
| 危险描边 | `#fff` | `1px #A61B29` | `#A61B29` | 34px | 0 16px | 驳回、作废、删除 |
| 主按钮-禁用 | `#C9B7BB` | 无 | `#fff` | 34px | 0 16px | 无权限 / 状态不允许 |

- 按钮间距 8px；表格行内操作间距 4px；图标按钮 28×28。
- 禁止纯图标无 tooltip 的危险操作。

## 2. 表单 Form

- 标签右对齐，宽 100–120px，颜色 `--text2`；必填星号 `#A61B29`，紧贴标签右侧。
- 输入框高 34px，圆角 6px，内边距 0 12px，描边 `#E7DFDC`，聚焦 `#5B2533` + `0 0 0 2px rgba(91,37,51,.10)`。
- 单列宽 360–520px；双列栅格间距 24px；说明文字 12px `--text3`，距输入框 4px。
- 日期范围、人员、组织、字典、级联一律使用对应控件，不用文本框代替。
- 保存前去除首尾空格；金额控件禁用负数；`项目编号` 后端生成，前端只读。
- 关闭抽屉/弹窗时若表单已变更，弹出「放弃未保存内容？」确认；复杂表单提供「保存草稿」。

## 3. 表格 Table

- 表头高 42px，背景 `#F7F0EE`，13px/600，颜色 `--text2`。
- 行高 44px，行分隔线 `1px #EFE8E5`，悬停 `#FCF8F7`，选中 `#F3E9EB`。
- 表头不写死宽度：`min-width` 按内容设置（编号 140 / 名称 220 / 状态 96 / 时间 168 / 操作 150），容器允许横向滚动。
- 编号、状态、日期、操作列 `white-space: nowrap`。
- 金额列右对齐 + 等宽数字；头像/海报列 40×40 圆角 4px。
- 空数据：48px 图标 + 「当前筛选条件下无记录，清空筛选或新建捐赠项目」。
- 加载：`v-loading` 局部遮罩，不白屏。

## 4. 卡片 Card

- 白底，圆角 8px，描边 `1px #E7DFDC`，无阴影，内边距 16px。
- 卡片标题区高 48px，标题 15px/600，右侧可放「共 N 条」或操作按钮。
- 指标卡：标题 12px `--text3` + 数字 28px/600（等宽）+ 环比 12px（涨 `#2D765C`，跌 `#A61B29`）。
- 卡片之间间距 16px；看板 6 个指标卡一行 6 列（1440px 下每列约 210px）。

## 5. 标签 Tag / 状态

- 高 22px，圆角 4px，内边距 0 8px，字号 12px，1px 同色系描边 + 浅底。
- 状态映射（文字必须出现，不能只靠颜色）：
  - 蓝灰 `#5B6472` / `#F1F2F4`：待审核、待核对、草稿
  - 青绿 `#2F6F6A` / `#EAF3F2`：报名中、进行中、执行中
  - 绿 `#2D765C` / `#EAF4EF`：已通过、已认证、已完成、已结项、已发放
  - 橙 `#B4761F` / `#FBF1E1`：候补、即将超时、待验收
  - 红 `#A61B29` / `#FBEBED`：已驳回、异常、已取消
  - 灰 `#6B5F5C` / `#F2EFEE`：已归档、已停用

## 6. 弹窗与抽屉

- 弹窗宽 640px（表单）/ 880px（详情），圆角 8px，标题 16px/600，底部按钮右对齐（取消在左、主按钮在右）。
- 抽屉宽 520px（审批）/ 720px（详情），从右滑入，顶部固定单据摘要（编号、状态、责任人），底部固定操作条。
- 审批抽屉必须同时展示：当前节点、可执行操作、原因输入（≥5 字校验）。
- 危险确认弹窗：标题含操作名，正文说明不可逆后果，按钮为「取消 / 确认驳回」。

## 7. 分页 Pagination

- 右对齐，`total` 在左、页码居中、每页条数下拉在右，选项 10 / 20 / 50，默认 10。
- 切换筛选条件后页码回到第 1 页。
- 分页下方留 14px 内边距。

## 8. 其他

- **时间轴**：左侧 2px 竖线 `#E7DFDC`，节点 8px 圆点（完成 `#2D765C`、当前 `#5B2533`、待办 `#C9B7BB`），右侧标题 13px/600 + 时间 12px `--text3` + 描述 13px `--text2`。
- **进度条**：高 8px，圆角 4px，底 `#F1EAE8`，填充 `#2F6F6A`；超过 100% 显示 `#B4761F`。
- **上传**：拖拽区高 96px，虚线 `1px #D9CDCA`，圆角 6px；已上传显示 96×72 缩略图 + 文件名 + 删除；禁止手填 URL 的输入框。
- **消息中心**：抽屉 420px，单条 12px 上下内边距，未读左侧 6px 主色圆点，点击跳转 `biz_url`。
- **图表**：容器高 260px，标题 14px/600，图例 12px；柱/线主色系，环图用 6 色序列；点击图形跳转带筛选的列表。
